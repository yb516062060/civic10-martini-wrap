# 10th Gen Civic Sedan Martini Wrap Concept

This repo contains ready-to-edit SVG concept files for a Martini-inspired wrap layout on a 10th Gen Honda Civic Sedan.

## Included files
- `design/hood_main.svg`
- `design/left_side_main.svg`
- `design/right_side_main.svg`
- `design/trunk_main.svg`
- `design/preview.pdf`

## Color palette
- Deep navy: #0D2B67
- Sky blue: #5DA5D4
- Central red: #C8102E
- White: #FFFFFF

## Default proportions
- Center red bar: 110 mm
- Left/right sky blue: 200 mm each
- Left/right deep navy: 170 mm each
- Side stripe separation: 15 mm
- Hood logo diameter: 140 mm
- Door logo diameter: 90 mm
- Trunk logo diameter: 130–150 mm

## Notes
- This is a concept layout for private visualization / mockup / prep work.
- The included SVG files are editable and can be imported into Blender, Illustrator, Figma, or Inkscape.
- The PDF is a minimal printable concept sheet; for real production use, convert to a production-ready cut file with bleed and safety guides.
- The official Martini mark is a trademark. Use it only for private or internal concept work, or obtain permission for public/commercial usage.

## Render suggestion
Use a white gloss paint base and place the SVG layers as decals on the model with alpha transparency in Blender Cycles.
